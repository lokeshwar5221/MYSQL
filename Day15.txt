Types of Joins
______________

Inner join
left join
Right join
Full join
Cross join
Self join


Inner Join
__________

Returns only the rows that have matching value in both tables.

syntax
______

select columns
from table1
inner join table2
on table1.common_column=table2.common_column;

Left join
_________

Returns all rows from the left table and the matched rows from the right table. If no match,
Null values appear for right table columns.

syntax
______

select columns
from tables1
left join table2
on table1.common_column=table2.common_column;

Right join
__________


Returns all rows from the left table and the matched rows from the right table. If no match,
Null values appear for left table columns.

syntax
______


select columns
from tables1
right join table2
on table1.common_column=table2.common_column;

Full join
_________
to simulate use the union of left join and right join.

syntax
______

select columns
from tables1
left join table2
on table1.common_column=table2.common_column;
union
select columns
from tables1
right join table2
on table1.common_column=table2.common_column;

cross join
__________

returns cartesian product--> every row from the first table with every row from the second table.

syntax
______

select columns
from table1
cross join table2;

self join
_________

A table joined with itself.

syntax
______

select a.columns,b.columns
from table1 a
inner join table1 b
on a.common_column=b.common_column;


Views
_____

What is view?
_____________

A view is a virtual table in MySQL . Biult from the result of stored select statement . It looks and behaves
like regular table when you query it.

You can select from it, filter it and join it . but it doesn't store any data on its own. Every time view is queried ,
MySQL runs its underlying select statement against in real tables and returns the result.

Why do we need views?
_____________________

simplify complex queries.
reuse query logic.
data security.
logical data independence.

Advantages
__________

security.
reusability.
simplicity.
consistency.
maintainability.
custom data presentation.
no extra storage cost.

Creating views
______________

create view view_name as
select columns from table
where condition

Altering views
______________

alter view view_name as 
select new_columns
from new_tables.

Dropping view
_____________

drop view view_name
drop view if exists view_name;
